Awards are the Task Force's way of recognizing exceptional performance, heroism, and dedication to the mission. Each award carries a ribbon and medal, an experience point (XP) value, and a set of requirements that must be met before it can be presented.

The gallery below is loaded live from the Task Force members portal, so it always reflects the latest awards, descriptions, and criteria. If an image or entry appears out of date, it will correct itself on the next load.
